**Branch:** `release/1.11-glossary-chatbot`

## Context

v1 shipped as seed lookup. This upgrade makes Glossary a **Groq tool-calling agent** over `glossary_seed.json`, with deterministic fallback when `GROQ_API_KEY` is missing.

## Locked decisions

| Decision | Choice |
|----------|--------|
| UX | Multi-turn agent chatbot (prose-first) |
| Knowledge | Seed via tools only |
| Runtime | Official `groq` SDK `chat.completions` + local allowlist |
| Default model | `openai/gpt-oss-120b` (`GLOSSARY_LLM_MODEL`) |
| Tools | `search_glossary`, `get_glossary_term`, `refuse_out_of_scope` |
| Forbidden | Portfolio/market/web tools; LangChain |
| Degraded | Deterministic matcher if no key / Groq fails |

## Done when

Agent multi-turn answers via Groq + seed tools; advice/dump refused; fallback works without key; Varsity links optional citations.
