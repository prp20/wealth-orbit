## Outcome

Agentic chat can **present and explain Stance Engine results** (Buy/Hold/Avoid + evidence) and answer research questions from **stored** metrics with citations — extending 1.19’s evidence-bound agent. The agent **must not invent labels**. If the user asks “should I buy X?”, the agent **calls/displays StanceEngine output** (and optional L3 explanation); it does not freestyle a recommendation.

**1.11 glossary-only mode remains available** (terms from Varsity seed).  
**1.19 refuse-buy/sell rule is replaced** for questions that map to stance by the policy pivot from 1.23 — but only via engine-backed answers.

Chat threads and history live in the **private store** (multi-user ready).

### Tooling contract (normative)

Agent runtime may only use allowlisted tools, for example:

1. `get_glossary_term(term)` — 1.11 seed  
2. `get_stored_metric(instrument, metric_keys)` — MarketResearch reads  
3. `get_stance(instrument)` — 1.23 (+ mode from 1.25)  
4. `get_portfolio_stance(portfolio_id)` — 1.24, authz  
5. `explain_stance(stance_payload)` — 1.26 adapter, optional  

**Forbidden tools:** place_order, scrape_live_price_for_answer, web_search_unbounded (unless separately approved in a future release).

### Answer policy

- Numbers in answers must appear in tool results.  
- If user asks for buy/sell and stance exists → present stance label + evidence + as_of + engine_version.  
- If stance missing → refuse personalized label; suggest which data to sync (checks).  
- Always show citations / as-of for quantitative claims.
