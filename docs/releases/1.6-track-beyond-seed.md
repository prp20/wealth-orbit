# Release 1.6 — Track beyond seed

**Status:** Outline — freeze when 1.5 ships  
**Milestone:** `1.6`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

A user can add and track a mutual fund, stock, or index that is **not** in the seed catalog (India-first), then sync history on demand via existing jobs.

## Foundation

- [ ] Add-by-code/search writes into Postgres masters without silent duplicates
- [ ] Failed lookup/sync is logged with instrument identity
- [ ] Re-add of an already-tracked instrument is idempotent or clearly rejected

## Backlog

- [ ] UI to search or enter code for MF, stock, or index outside seed
- [ ] Persist new master row(s) in Postgres when found
- [ ] Trigger on-demand history sync for the new instrument
- [ ] Show honest empty/error when the instrument cannot be resolved
- [ ] Document India-first scope and supported identifier types

## Out of scope

Multi-country universes (Later); auto-import entire exchanges; live trading; brokers.

## Exit

User can add a non-seeded India MF, stock, or index and sync history.

## Idea map

Track new mutual funds, stocks, or indices beyond seed.
