# Release 1.11 — Glossary chatbot

**Status:** Approved for freeze  

**Milestone:** `1.11`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

A chat surface explains investing terms (definitions only). It does not give buy/sell/switch advice. Guardrails in v1.2 §7 apply. Answers draw from the curated seed at [docs/varsity_docs/glossary_seed.json](../varsity_docs/glossary_seed.json) and cite Varsity chapter URLs where used.

## Foundation

- [ ] Responses that look like advice are refused with a clear message
- [ ] Chat failures are logged without leaking secrets
- [ ] No invented prices or portfolio numbers in glossary mode
- [ ] Never return full Varsity chapter/PDF text verbatim; refuse dump/redistribute requests

## Backlog

- [ ] Chat UI for glossary / terminology questions
- [ ] Load curated terms from `docs/varsity_docs/glossary_seed.json` (our definitions)
- [ ] Answer definitions of common investing terms clearly
- [ ] Cite Varsity module/chapter URL from the seed `sources` when a term was seeded from that chapter
- [ ] Refuse buy, sell, or switch recommendations
- [ ] Document scope: definitions only; PDFs stay offline research copies

## Out of scope

Agentic research over portfolio metrics (1.19); live trading; personalized recommendations; shipping Varsity PDFs; scraping Innerworth wholesale into the app.

## Exit

User can ask for a term definition and get a clear glossary answer (with citation when available).

## Idea map

Chatbot that explains investing concepts (curated Varsity-cited terms).
