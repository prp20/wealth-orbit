# Release 1.11 — Glossary chatbot

**Status:** Approved for freeze  

**Milestone:** `1.11`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

A chat surface explains investing terms (definitions only). It does not give buy/sell/switch advice. Guardrails in v1.2 §7 apply. Answers draw from the curated seed at [docs/varsity_docs/glossary_seed.json](../varsity_docs/glossary_seed.json) and cite Varsity chapter URLs where used.

With `GROQ_API_KEY` configured, multi-turn glossary chat uses a Groq tool-calling agent over the seed (`POST /api/v1/glossary/agent/chat`). Without a key or on Groq failure, the same UI degrades to deterministic seed lookup (`mode: fallback`). Single-turn `POST /api/v1/glossary/chat` always uses the matcher.

## Foundation

- [x] Responses that look like advice are refused with a clear message
- [x] Chat failures are logged without leaking secrets
- [x] No invented prices or portfolio numbers in glossary mode
- [x] Never return full Varsity chapter/PDF text verbatim; refuse dump/redistribute requests

## Backlog

## Out of scope

Agentic research over portfolio metrics (1.19); live trading; personalized recommendations; shipping Varsity PDFs; scraping Innerworth wholesale into the app.

## Exit

User can ask for a term definition and get a clear glossary answer (with citation when available).

Exit smoke: `tests/test_glossary_api.py::test_glossary_exit_smoke_ipo_and_advice_refusal`, agent guards in `tests/test_glossary_agent.py`, and matcher tests in `tests/test_glossary_seed_matcher.py`.
