# Release 1.16 — Indicator strategies

**Status:** Outline — freeze when 1.15 ships  
**Milestone:** `1.16`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

Built-in strategies using RSI, Bollinger Bands, EMA, and/or SMA run on stored history with disclosed rules and dated signals.

## Foundation

- [ ] Strategy run inputs and failures are logged
- [ ] Signal rows upsert cleanly on re-run

## Backlog

- [ ] At least one RSI-based and one MA/BB-based built-in strategy
- [ ] Rules disclosed in UI or docs
- [ ] Run on stored history; show signal timestamps and rule version
- [ ] “Research signal, not advice” labelling
- [ ] Note look-ahead / point-in-time rules in docs

## Out of scope

User `.py` plugins (1.16); live orders; chart drawing tools.

## Exit

One strategy run produces dated signals on stored history with disclosed rules.

## Idea map

Various trading strategies using RSI, BB, EMA, SMA.
