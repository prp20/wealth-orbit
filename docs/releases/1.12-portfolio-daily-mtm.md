# Release 1.12 — Portfolio daily MTM

**Status:** Outline — freeze when 1.10 ships  
**Milestone:** `1.12`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

Signed-in users see current value and gain/loss when NAV or price exists, with as-of dates. Missing market data stays honest empty — never a fabricated zero gain.

## Foundation

- [ ] Batch latest NAV/price for held assets (no N+1 per holding)
- [ ] Missing quotes do not become zero

## Backlog

- [ ] MF holdings valued from latest NAV when present
- [ ] Stock holdings valued from latest close when present
- [ ] Absolute gain/loss (and optional day change) with observation date
- [ ] Home and Portfolio replace permanent “Not available” when values exist

## Out of scope

XIRR, PDF reports, broker sync, live trading.

## Exit

Home/Portfolio show gain with as-of, or honest empty when data is missing.

## Idea map

Portfolio tracking daily changes.
