# Release 1.7 — Stock screener

**Status:** Outline — freeze when 1.6 ships  
**Milestone:** `1.7`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

Users can filter and sort stocks on stored ratios/valuation (same discovery idea as the existing fund screener).

## Foundation

- [ ] Screener reads stored snapshots only (no live scrape per request)
- [ ] Query is batched / indexed enough for the current catalog size

## Backlog

- [ ] API: multi-filter stock screen (sector/industry + key ratios/valuation)
- [ ] UI page with filters, sort, pagination
- [ ] Nav or header link from Stocks list
- [ ] Empty and “no metrics yet” states are honest

## Out of scope

Saved screens, screen alerts, fund-screener redesign, Strategy Lab.

## Exit

User can filter/sort stocks and open a detail page from a result row.

## Idea map

Stock and mutual fund screeners (stock side).
