# Release 1.19 — Agentic research chat

**Status:** Outline — freeze when 1.18 ships  
**Milestone:** `1.19`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

An agentic chat answers research questions from **stored** app metrics only, with citations. It does not invent numbers and does not give buy/sell/switch advice. Guardrails in v1.2 §7 apply.

## Foundation

- [ ] Answers that lack stored evidence refuse or say unknown
- [ ] Citations point to stored metrics / as-of where claimed
- [ ] Buy/sell/switch advice is refused
- [ ] Agent runs/failures are logged

## Backlog

- [ ] Chat that can query stored research/portfolio metrics for explanations
- [ ] Require citations to stored values (no invented figures)
- [ ] Suggest **checks** only (what to look at), never trade actions
- [ ] Honest empty when data is missing
- [ ] Document evidence-bound contract for operators

## Out of scope

Live trading; autonomous order placement; inventing peer data; glossary-only mode (1.11).

## Exit

Agentic chat cites stored metrics only and refuses buy/sell advice.

## Idea map

Agentic AI / agentic chat grounded in stored data.
