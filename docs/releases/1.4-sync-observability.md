# Release 1.4 — Sync observability

**Status:** Outline — freeze when 1.3 ships  
**Milestone:** `1.4`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

Operators can see why a market sync failed and retry without creating duplicate NAV/OHLC/statement/index rows.

## Foundation

- [ ] Structured error logging for sync/API failures (no secrets)
- [ ] Job terminal status persisted (SUCCEEDED / FAILED / CANCELLED)

## Backlog

- [ ] Failed job reason visible from the UI or a simple jobs status path
- [ ] Transient failure retry where safe
- [ ] Confirm upserts on NAV, OHLCV, statements, holdings, indexes (document keys)
- [ ] Freshness still shown when last sync failed (stale, not silent)

## Out of scope

New screeners, portfolio MTM, Strategy Lab, brokers.

## Exit

Fail a sync on purpose, see the reason, retry, and confirm no duplicate market rows.

## Idea map

Rerun / tighten data model (logging, dedup, retrieval).
