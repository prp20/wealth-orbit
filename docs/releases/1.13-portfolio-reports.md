# Release 1.13 — Portfolio reports

**Status:** Outline — freeze when 1.12 ships  
**Milestone:** `1.13`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

One simple exportable report from the local portfolio: invested cost, current value when available, sleeve mix, with as-of dates.

## Foundation

- [ ] Report generation failures are logged
- [ ] Report uses the same valuation rules as 1.11 (no silent zeros)

## Backlog

- [ ] Report content: cost, value (if any), MF/stock sleeves
- [ ] Export as CSV or HTML (pick one at freeze; default CSV)
- [ ] Header includes as-of for prices/NAV used
- [ ] Entry point from Portfolio page

## Out of scope

Tax reports, XIRR (1.13), broker statements, AI narrative reports.

## Exit

User can download one report from local holdings.

## Idea map

Reports generation.
