# Release 1.18 — Strategy backtesting

**Status:** Outline — freeze when 1.17 ships  
**Milestone:** `1.18`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

A backtest engine runs built-in (1.15) and/or plugin (1.16) strategies on **stored** history and returns summary metrics (e.g. CAGR, max drawdown) with disclosed cost assumptions and look-ahead rules.

## Foundation

- [ ] Backtest runs are logged (strategy, symbol/window, version)
- [ ] Look-ahead / point-in-time rules are documented and enforced
- [ ] Costs/slippage assumptions are disclosed in the result
- [ ] Insufficient history yields honest failure, not fake performance

## Backlog

- [ ] Engine accepts a strategy (built-in or plugin) + symbol/window
- [ ] Produce equity curve summary: CAGR, max drawdown (minimum set)
- [ ] Disclose costs and look-ahead policy in UI/export
- [ ] Persist or export one reproducible run result
- [ ] Label results as research simulation, not advice
- [ ] Smoke one built-in strategy end-to-end on stored history

## Out of scope

Live order placement; portfolio optimization marketplace; multi-country universes; AI-generated strategies.

## Exit

One strategy backtest returns CAGR/drawdown with disclosed assumptions.

## Idea map

Strategy engine with back-testing.
