# Release 1.17 — Discoverable `.py` strategy plugins

**Status:** Outline — freeze when 1.16 ships  
**Milestone:** `1.17`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

A user can add a strategy as a `.py` module under a defined package; the UI discovers it, lists it, and can run it on stored history without crashing the app.

## Foundation

- [ ] Failed plugin load is visible and isolated
- [ ] No broker secrets required in plugins
- [ ] Run results logged with plugin name/version

## Backlog

- [ ] Defined directory/package for strategy plugins
- [ ] Registration contract (name, description, parameters)
- [ ] UI lists discovered strategies; inspect + run on a symbol/window
- [ ] Ship one sample plugin
- [ ] Document how to add a new `.py` file

## Out of scope

Live trading, marketplace of plugins, multi-country universes, agentic code generation.

## Exit

Sample plugin appears in the UI and runs without crashing the app.

## Idea map

User adds a new strategy using a `.py` file; discoverable in UI.
