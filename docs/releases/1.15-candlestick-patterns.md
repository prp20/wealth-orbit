# Release 1.15 — Chart / candlestick patterns

**Status:** Outline — freeze when 1.14 ships  
**Milestone:** `1.15`  
**Parent:** [Nivesh_Product_Requirements_and_Roadmap_v1.2.md](../Nivesh_Product_Requirements_and_Roadmap_v1.2.md)

## Outcome

A documented set of **chart / candlestick patterns** is detected from stored OHLCV and listed for a symbol as stored records. Chart doodles / interactive overlays are not required for exit.

## Foundation

- [ ] Pattern job failures are logged
- [ ] Re-run for the same window/version does not duplicate pattern rows

## Backlog

- [ ] Detect a small documented pattern set from stored OHLCV
- [ ] Persist name, symbol, date, parameters, calculation version
- [ ] UI lists patterns for a symbol (table)
- [ ] Label as research signal, not advice

## Out of scope

Interactive chart overlays as the deliverable; live trading; `.py` plugins (1.16); deeper indicator tables (1.10).

## Exit

Chart patterns listed for a symbol from stored history.

## Idea map

Chart / candlestick pattern recognition.
